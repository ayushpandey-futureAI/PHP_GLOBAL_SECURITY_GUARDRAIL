## Reporting a Vulnerability

The PHP Universal Security Vaccine team takes the security of this software and its protected downstream applications with the utmost seriousness.

If you believe you have discovered a vulnerability, bypass, or false negative in the PHP Universal Vaccine:

1. **DO NOT open a public GitHub issue.**
2. Send an email to **Ayush Pandey** at `ayushpandey-futureAI` via GitHub security advisory or direct email to `Bhaskarauthor@gmail.com`.
3. Please include:
   - Specific payload string or exploit proof-of-concept (PoC).
   - Target PHP version and web server environment (e.g. PHP 8.2-FPM on NGINX).
   - Expected behavior vs actual observed behavior.

### Response Timelines (SLA)
* **Initial Triage:** Within **24 hours**.
* **Remediation & Patch Formulation:** Within **72 hours**.
* **Public CVE & Advisory Release:** Coordinated disclosure within **14 days** of patch distribution.
